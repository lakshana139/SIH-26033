#Problem Title
#SIH 26033: Multiple intermediaries reduce farmers earnings and increase consumer prices.

#Problem Creater's Organization
#Ministry of Consumer Affairs, Food & Public Distribution

#Theme
#Agriculture, FoodTech & Rural Development

#Problem Description
#Expected Solution: Create a digital marketplace that:

• Connects farmers/FPOs directly with consumers and bulk buyers.
• Provides logistics support.
• Uses AI for demand forecasting and route optimization.

#Benefits:

• Better prices for farmers.
• Lower prices for consumers.
• Reduced supply chain inefficiencies.

#Proposed Solution
1. we propose to develop a website that connects farmers directly with customers.
2. farmers can upload their products, prices and quantities, while customers can view the products and place orders easily.
3. The website also provides delivery support, reduces middlemen, helps farmers get better prices and allows customers in resonable prices.
4. it makes the buying and selling process simple and easy to manage.

#Technical Approach
1. HTML,CSS and JavaScript are used to create the website design.
2. python is used t manage the website functions.
3. MySQL is used to store farmer, customer and product detials.
4. Farmers and customer can register and log into the website.
5. Farmers can upload products with their prices and available quantities.
6. customers can view products, place orders and check delivery detials.

##Feasibility and Viability
1. this project can developed using basic web technologies.
2. It requires less development cost and simple tools.
3. Farmers can easily use the website using mobile phones or computer.
4. Delivery services can help transport to customers.
5. The website can be improved by adding more features in future.

#Impact and Benefits

1. Helps farmers sell their products directly to customers.
2. provides fresh agricultural products at reasonable prices.
3. reduces the role of average men in selling.
4. Saves time and makes products ordering easier.
5. Supports small farmers and rural business.
